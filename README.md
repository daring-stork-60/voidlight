**VOIDLIGHT** — a neon arena survival shooter. Pilot a lumen-ship through the void, blast void creatures, harvest their cores, chain combos, and unleash the nova bomb. Survive every wave.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Or open `game/index.html` directly in a desktop browser — the game is plain static files with no network requests and no build step.

## Controls

- **WASD / arrows** — move
- **Mouse** — aim, **click / Space** — fire
- **E / right-click** — nova bomb (when the meter is full)
- **P / Esc** — pause · **M** — mute · **R** — restart after game over
- Touch: drag to move, auto-fire at the nearest enemy.

## The game

Five enemy types with their own behaviour (chasers, shooters, splitters, orbiters, and the Warden elite every 5th wave), a combo multiplier, four power-ups (spread shot, rapid fire, shield, magnet), core drops that charge the nova, particles, screen shake, and a fully synthesized WebAudio soundscape — no audio files, no copied art or names. Everything is original.
